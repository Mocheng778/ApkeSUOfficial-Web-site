核心能力

从内核策略、ksud 到 Manager，ApkeSU 把关键状态放在同一条链路里，让异常更容易被发现和处理。

LKM 底层 Root

无需修补 Boot 镜像即可加载内核模块，完整 Root 权限，兼容 SELinux 强制模式。

KPatch Root 隐藏

清除 Root 检测痕迹，适配银行、支付、游戏风控软件的安全校验。

App Profile 管理

按应用精确设置 uid、gid、capabilities、SELinux 与挂载命名空间，权限颗粒度更细。

全自动救砖防护

自动备份 boot 分区，卡 logo、无限重启时自动回滚修复，降低刷机风险。

快捷工具箱

一键进入 Rec、Fastboot、EDL 深度下载模式，无需记忆复杂指令。

模块统一管理

批量开关 Root 模块，自动检测版本更新，模块生态一站式管理。

安装教程

1. Android13+新机：提取init boot镜像，用ApkeSU进行修补，通过Kernel Flasher工具刷入。若从KernelSU转Root管理器，仅需授予ApkeSU超级用户权限，选择「推荐直接安装」模式即可；


2. 系统OTA升级后：独立槽位安装A/B槽，防止更新导致Root丢失，装入Boot分区使用。


3. Android 12及以下旧机型：使用Anykernel刷入指定的ak3包，选择指定的A/B分区。


4. ApkeSU更新：若发现内核与管理器版本不匹配，直接点击「工作版本→推荐直接安装」即可更新内核版本。
